How the Garmin script works

  1. Import Garmin's catalog once.
  2. Build or edit your workout in this page.
  3. Generate and copy the Garmin script.
  4. Open Garmin Connect in the browser where you are logged in.
  5. Press F12 and select Console.
  6. Paste the script and press Enter.

The script uses Garmin's captured workout endpoint. Garmin may request the current CSRF token. The script will ask for it if it cannot find it automatically.
